# Cases & Mockups — Corretoras de Seguros
> Repositório de demonstração de interfaces e arquiteturas institucionais de alta conversão para o setor de seguros — **Ri7 Consultoria**.

---

## 📌 Visão Geral

Este repositório reúne três propostas arquiteturais e visuais completas de mockups para corretoras de seguros, planejadas a partir de benchmarking aprofundado de concorrentes de mercado e desenhadas para solucionar os principais gargalos de conversão, lentidão e vícios de template do setor.

Inclui um **Showcase Hub** interativo para alternar rapidamente entre os mockups em reuniões comerciais com clientes, simulando tanto em viewport Desktop quanto Mobile.

---

## 🚀 Os 3 Mockups Desenvolvidos

### 1. [NovaSeg Digital (Case Insurtech)](cases/insurtech/index.html)
* **Perfil:** Corretora moderna, digital-first, focada na descomplicação.
* **Público:** 25 a 45 anos, autônomos, startups e quem valoriza contratação 100% digital.
* **Destaques:**
  * Micro-simulador interativo em 2 passos na dobra principal (Hero).
  * Seletor de abas instantâneo entre *Pessoa Física* e *Pequenas Empresas (PME)*.
  * Ticker infinito com as maiores seguradoras homologadas SUSEP.
  * WhatsApp inteligente com mensagens pré-configuradas contextuais.

### 2. [Valence Risk Advisory (Case Corporate & Wealth)](cases/corporate/index.html)
* **Perfil:** Corretora tradicional e consultoria boutique de gestão de riscos corporativos.
* **Público:** Diretorias financeiras (CFOs), incorporadoras, frotistas e famílias empresárias.
* **Destaques:**
  * Posicionamento nobre e editorial (Plus Jakarta Sans & Lora).
  * Seção do **Núcleo Técnico de Sinistros com SLA de 15 minutos**.
  * 4 Linhas de Solução: Frotas & Logística, Obras & Riscos Patrimoniais, D&O/Governança e Vida Resgatável.
  * Prova social executiva com credenciais verificadas no LinkedIn.

### 3. [MegaPreço Seguros (Case Alta Conversão Varejo)](cases/comercial/index.html)
* **Perfil:** Corretora comercial agressiva orientada a volume de vendas e menor preço garantido.
* **Público:** Varejo em massa (Auto, Moto, Caminhão, Saúde Familiar e Residência).
* **Destaques:**
  * Hero Split-screen com formulário de cotação fixado na primeira dobra.
  * Ancoragem visual de preços (*"A partir de R$ 49/mês"*).
  * Tabela de confronto direto: *MegaPreço vs. Bancos Tradicionais*.
  * Sticky Bottom Bar para cotação imediata em dispositivos móveis.

## 🛠️ Como Executar Localmente

### Pré-requisitos
* Node.js 18+ instalado.

### Passo a passo
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento local
npm run dev

# 3. Compilar para produção (gera arquivos estáticos na pasta dist/)
npm run build
```

Ou simplesmente abra qualquer arquivo `index.html` diretamente em seu navegador.
