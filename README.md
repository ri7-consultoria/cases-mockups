# Cases & Mockups — Corretoras de Seguros
> Repositório de demonstração de interfaces e arquiteturas institucionais de alta conversão para o setor de seguros — **Ri7 Consultoria**.

---

## 📌 Visão Geral

Este repositório reúne duas abordagens conceituais completas de mockups para corretoras de seguros, planejadas a partir de benchmarking aprofundado de concorrentes de mercado e desenhadas para solucionar os principais gargalos de conversão, lentidão e vícios de template do setor.

Inclui um **Showcase Hub** interativo para alternar rapidamente entre os mockups em reuniões comerciais com clientes, simulando tanto em viewport Desktop quanto Mobile.

---

## 🚀 Os 2 Mockups Consolidados

### 1. [NovaSeg Digital (Case Insurtech)](cases/insurtech/index.html)
* **Perfil:** Corretora moderna, digital-first, focada na descomplicação e velocidade.
* **Público:** 25 a 45 anos, autônomos, startups e quem valoriza contratação 100% digital.
* **Destaques:**
  * Micro-simulador interativo em 2 passos na dobra principal (Hero).
  * Seletor de abas instantâneo entre *Pessoa Física* e *Pequenas Empresas (PME)*.
  * Ticker infinito com as maiores seguradoras homologadas SUSEP.
  * WhatsApp inteligente com mensagens pré-configuradas contextuais.

### 2. [Valence Consultoria de Seguros (Case Humanizado & Consultivo)](cases/corporate/index.html)
* **Perfil:** Corretora de alta confiança, acolhimento e consultoria pessoal e patrimonial.
* **Público:** Famílias, empresários, executivos e clientes que valorizam falar com uma pessoa real de confiança.
* **Destaques:**
  * **Banner fotográfico acolhedor na Hero** transmitindo proximidade e segurança.
  * **Seção Exclusiva "Quem está ao seu lado"** com foto em destaque do corretor, biografia com propósito, credenciais SUSEP e canal direto no WhatsApp pessoal.
  * **Banner mid-page sobre tranquilidade e família**.
  * **Núcleo de Sinistros Humanizado**, garantindo que o cliente nunca falará com robôs ou URAs na hora do sinistro.
  * Prova social com depoimentos reais de clientes assistidos.

## 🛠️ Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento local
npm run dev

# 3. Compilar para produção (pasta dist/)
npm run build
```

Ou simplesmente abra o arquivo `index.html` diretamente em seu navegador.
